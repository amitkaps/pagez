<!-- Expect: each <style> is raw HTML, written where it is in the body, unlayered. A page's CSS
belongs in style.css, but a page kept as one file can carry it this way. -->

```=html
<style>
  h1 {
    color: teal;
  }
</style>
<p class="note">Raw HTML beside the first style, which stays in the body.</p>
```

# Page CSS

Prose between the two blocks.

```=html
<style>
  .note {
    font-style: italic;
  }
</style>
```
